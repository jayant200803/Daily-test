3. TTS metric comparison

Radar values are scaled 0 to 100 where higher is better, for visual comparison only (English TTS).

4. How each number is measured

Time-to-first-audio (TTFA): how long from sending the text until the first audio is received, with the network round-trip subtracted so it reflects the provider's own speed.
TTFA = first-audio-byte time − network round-trip
Full generation time: how long until the whole audio clip is produced.
Speed (RTF, Real-Time Factor): generation time divided by how long the audio plays. Below 1 is faster than real time; near 1 is slow for live use.
RTF = generation time ÷ audio duration
Correctness (WER): the generated audio is transcribed by a neutral speech recognizer (Deepgram) and compared to the input text. Lower is better.
WER = (substitutions + insertions + deletions) ÷ total words
Japanese uses CER (character error rate), since Japanese has no spaces between words.
Naturalness: how clean and human the voice sounds, from the Harmonics-to-Noise Ratio (HNR) of the audio, mapped to a 1 to 5 score. Higher is better.
Naturalness = 1 + HNR ÷ 7.5 (clamped 1 to 5)
Prosody (expressiveness): how much the pitch varies. Flat speech sounds robotic; more variation is more expressive.
Prosody = standard deviation of pitch (Hz)
Robustness: correctness (WER) measured only on hard sentences (numbers, currency, symbols, email). Lower is better.
STT latency (time-to-first-word): the audio is streamed to the provider's real-time API and we time the first word. This is the metric that matters for live voice agents. AssemblyAI runs in batch mode, so compare its accuracy, not its latency.

6. Method

Each provider received the identical test set and was measured the same way, at the same time, from one machine. Latency is reported with the network removed so it reflects provider speed rather than our location. Every value on this page is an average of the measured results; nothing is estimated.

  • Dataset: general, technical, and hard-case sentences (English and Japanese).
  • TTS audio is generated via each provider's API, then analysed for duration, RTF, naturalness, prosody, and transcribed for correctness.
  • STT uses each provider's real-time streaming API (where available) on the same clean clip.

7. Summary

  • Atlas STT is fast (streaming time-to-first-word) and strong in Japanese.
  • Atlas TTS is the slowest to first audio and runs near real time (RTF ≈ 1), which is a limitation for live voice agents.
  • Cartesia and ElevenLabs lead on TTS speed; Deepgram is a strong all-rounder.
